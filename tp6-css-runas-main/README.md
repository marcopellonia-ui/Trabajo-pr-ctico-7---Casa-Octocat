## Decisiones de diseño 

Elegí una estética inspirada en un pergamino antiguo, utilizando una paleta de colores en tonos beige y marrón para mantener la temática. Busqué que la información fuera clara y fácil de leer, organizando cada tarjeta según la técnica de CSS que correspondía: Position para ubicar elementos de forma precisa, Flexbox para distribuir el contenido en una dirección y Grid para organizar la información en filas y columnas. Además, procuré mantener un diseño uniforme entre las tres tarjetas.

## Técnica que me resultó más sencilla

La técnica que me resultó más sencilla fue Flexbox, porque me ayudó a organizar y alinear los elementos de forma práctica y sencilla. Siento que es más personalizable y que siempre hay una propiedad que soluciona lo que buscaba hacer.

## Dificultad encontrada

La mayor dificultad fue adaptar la distribución de los elementos a cada técnica sin modificar la estructura del HTML y lograr que el diseño se mantuviera ordenado y coherente. Me costó porque no me permitía crear clases, por ejemplo, por lo que tuve que seleccionar ciertos elementos usando sus elementos padre.
